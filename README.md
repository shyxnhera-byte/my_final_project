## Description
A browser-based inventory and sales tracker built with HTML , CSS and Javascript.ShopTracker helps small store owners manage products, record sales and monitor stock levels _ all from a clean, dashboard-style interface.
## Features
1. Dashboard - Live overview of total products, today's sales, total transactions and low stock alerts.
2. Inventory - Add, Edit and delete products with automatic status(In Stock, Low Stock, Out of Stock).Includes a search bar to filter products by name or category.
3. Sales - A point-of-sale style page to build a cart, calculate totals and complete sales. Stock quantities update automatically after each sale.
4. Sales History - A running log of every completed sale, including date, products , total and payment method.

Browser localStorage for data persistence
## How it works
All data _ products and sales_is stored directly in the browser using localStorage.
This means:
The app works fully offline, with no server or database.

Data persists betweeb visits , as long as you use the same browser on the same device.

Data does not carry over between different browsers, devices , or private/incognito windows_each is treated as a separate, empty storage space.
## Getting Started
1. Clone or download this repository.
2. Open index.html in your browser (or use a local server like VS Code's Live Server extension)
3. Start by adding a few products in Inventory, then record a sale on the Sales page to see the dashboard and history populata with real data.
